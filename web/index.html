Where AI is used, and where it isn't

A LangGraph graph on Azure Functions. Decisions are deterministic: the language model talks, it does not decide.

  1. AI + guardrail

    1 · Understand

    Regex in Spanish, Portuguese and English before the model; then Llama 3.3 70B with typed JSON output.

  2. No AI

    2 · Decide

    Versioned YAML rules × token scopes × each country's regulatory band.

  3. Model as input

    3 · Act

    Only typed, authorized tools. The pre-score informs; it never approves.

  4. No AI

    4 · Verify

    Every figure must appear in a citation. If the check fails, it answers from a template.

  5. Human

    5 · Escalate

    A handoff with context and reason, shown to the analyst.

What's next, and why it isn't here yet

Each gap with its cause and the next step. None is hidden.

Model Serving at runtime

The prescore-lgbm endpoint is ready and gives exactly the same result as the in-process model (p = 0.969). A cold endpoint takes over 25 s, so production runs the model in-process.

Next: switch to the endpoint once it stays warm.

Latency under load

p95 17.5 s with 10 concurrent users, against a target of 8 s; p50 is 2.7 s. Our code is no longer the tail: a per-customer SQL memo cut pre-checks from 14.8 s to 4.7 s (p50). The slowest turns wait in the pay-per-token queue of the 70B, and 5.6% of turns hit the 8B's rate limit; those fail safe and go to an advisor.

Next: provisioned throughput and a retry on 429; confirm with the same k6 test.

Embedding endpoint cost

bge-m3 runs without scale-to-zero during the evaluation. A cold start takes minutes, and the agent would fall back to lexical search.

Next: turn scale-to-zero back on after the evaluation.

A real held-out set

The dataset does not separate the five intents of the workflow.

Next: label real call transcripts.

Rate caps for Colombia and Mexico

Provisional values, not yet cited: the SFC publishes a monthly PDF and Banxico an interactive query tool.

Next: paste the two official figures per row.

Portuguese in the dataset

The dataset is 100% Spanish. We measure Portuguese with synthetic documents and cases, and we say so.

Next: real Portuguese conversations from the bank.
